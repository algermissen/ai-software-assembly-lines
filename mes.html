Architecture Overview

Execution layer managing production orders, scheduling resources, enforcing quality gates, tracking full genealogy, providing plant-floor visibility.

Technology Choices

  • Core Orchestrator: Temporal workflows.
  • State & Genealogy: Event sourcing + OpenTelemetry traces; Postgres/ClickHouse.
  • Dashboards: Grafana.

Defined Datapoints & Metrics

  • Order: id, risk_tier, status, current_station, lineage, token_budget.
  • KPIs: cycle time, on-time completion, resource utilization, quality gate pass rate.

Development / Operations Process Flow

  1. Intent to production order.
  2. Schedule stations, reserve capacity.
  3. Execute with progress events; handle Andon by blocking.
  4. Authorize deploy; post-deploy monitoring.
  5. Feed SPC and Kaizen.
