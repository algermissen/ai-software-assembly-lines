Architecture Overview

Stations as specialized agents or services with explicit quality checks that can halt flow (Jidoka). Andon events escalate to humans. WIP limits enforced. Kaizen loop updates guardrails from defect data.

Technology Choices

  • Orchestration: Temporal or Camunda for durable workflows.
  • Agents: LangGraph or custom with OpenTelemetry gen_ai instrumentation.
  • Quality Gates: GitHub Actions + policy as code (OPA).
  • Andon: Events to Slack/PagerDuty with full context.

Defined Datapoints & Metrics

  • Per station: arrival/start/end times, outcome, defect_type, confidence, human_interventions.
  • Andon: stop_count, mean_time_to_resolution, false_positive_rate.
  • Flow: WIP, cycle time, first-pass yield, rework loops.

Development / Operations Process Flow

  1. Validated intent pulled into Plan station.
  2. Implement station generates code; STOP + Andon on issues.
  3. Verify station runs automated checks.
  4. Review only for higher-risk.
  5. Deploy if green. Monitor feeds back.
  6. Every defect → Kaizen update to skills/tests/guardrails.
